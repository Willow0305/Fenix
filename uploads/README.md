# Uploads locais

Esta pasta existe apenas como convenção para desenvolvimento e testes controlados.

- Não versione arquivos enviados por usuários.
- Não use este diretório como armazenamento persistente em produção.
- Comprovantes e documentos devem ficar em armazenamento privado de objetos.
- O banco deve guardar somente metadados, hash/chave e referência segura.
- Use apenas arquivos sintéticos e não sensíveis nos testes.
